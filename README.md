# DANGEROUS WELDER: THE LAST SHIFT

Репозиторий браузерной игры. Сейчас готов этап 1: пустой цех на холсте 640×360.

**Репозиторий:** `KHaberland/dangerous_welder`  
**Статус:** этап 1 — окно, масштаб и цикл 60 кадров.  
**Девиз:** «Его хотели заменить роботами. Теперь роботам нужна замена».

Жанр: 2D-платформер / шутер / промышленная комедия.  
Стиль: ретроигры 90-х, современный пиксель-арт.  
Платформы: браузер на Windows, Android и iOS.

## Принцип

Сначала игра, в которую хочется играть ещё минуту. Управление, бой и шутка важнее архитектуры. Первая версия — один уровень на 3–5 минут.

Игра живёт в этом репозитории. Инженерный сайт остаётся отдельным проектом: без Django, без маршрута Next.js и без API сайта.

Рабочий порядок: никаких совещаний, отчётов и согласований. Следующий шаг — этап 2 в [plan.md](plan.md): бег и прыжок.

## Запуск этапа 1

Из корня репозитория:

```powershell
npm install
npm run dev
```

Откроется пустой цех. Счётчик кадров в левом верхнем углу прячется флагом `showFps` в `src/main.ts`.
